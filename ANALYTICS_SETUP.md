# Google Search Console & Analytics Setup Guide\n\n## 1. Google Search Console Setup\n\n### Step 1: Create Property\n1. Go to [Google Search Console](https://search.google.com/search-console)\n2. Sign in with your Google account (create if needed)\n3. Click \"Add property\"\n4. Enter URL: `https://fyclip.com`\n5. Select \"URL prefix\" method\n\n### Step 2: Verify Ownership\nChoose one verification method:\n\n#### Method A: HTML Meta Tag (Recommended)\n1. Copy the meta tag provided by GSC\n2. Add it to `src/app/layout.tsx` in the metadata object:\n```typescript\nexport const metadata: Metadata = {\n  title: \"...\",\n  // ... other metadata\n  verification: {\n    google: \"YOUR_VERIFICATION_CODE_HERE\",\n  },\n}\n```\n3. Deploy your site\n4. Click \"Verify\" in GSC\n\n#### Method B: HTML File Upload\n1. Download verification HTML file from GSC\n2. Place in `/public/` folder\n3. Deploy and verify\n\n#### Method C: DNS Record\n1. Add TXT record to your domain's DNS settings\n2. Record content provided by GSC\n3. Wait for DNS propagation (up to 48 hours)\n4. Verify in GSC\n\n### Step 3: Submit Sitemap\n1. In GSC left menu, go to \"Sitemap\"\n2. Click \"Add/test sitemap\"\n3. Enter: `https://fyclip.com/sitemap.xml`\n4. Click \"Submit\"\n\n### Step 4: Check Coverage Report\n1. Go to \"Coverage\" in left menu\n2. Check if pages are indexed\n3. Look for any errors or warnings\n4. Fix any issues found\n\n### Step 5: Core Web Vitals\n1. Go to \"Core Web Vitals\" in GSC\n2. Monitor your page performance\n3. Address any \"Poor\" or \"Needs improvement\" status\n\n## 2. Google Analytics 4 Setup\n\n### Step 1: Create GA4 Property\n1. Go to [Google Analytics](https://analytics.google.com)\n2. Click \"Admin\" (bottom left)\n3. Click \"Create Property\"\n4. Property name: \"FyClip\"\n5. Reporting timezone: Select your timezone\n6. Data stream: Follow setup wizard\n\n### Step 2: Add Measurement ID to Next.js\n1. Get your Measurement ID from GA4\n2. Create `src/lib/gtag.ts`:\n```typescript\nexport const GA_MEASUREMENT_ID = \"G_XXXXXXXXXX\" // Replace with your ID\n\nexport const pageview = (url: string) => {\n  window.gtag?.config({\n    page_path: url,\n  })\n}\n\nexport const event = (\n  action: string,\n  category: string,\n  label: string,\n  value: number = 1\n) => {\n  window.gtag?.event(action, {\n    event_category: category,\n    event_label: label,\n    value: value,\n  })\n}\n```\n\n3. Add to `src/app/layout.tsx`:\n```typescript\nimport Script from \"next/script\"\nimport { GA_MEASUREMENT_ID } from \"@/lib/gtag\"\n\n// In the JSX of your layout:\n<>\n  <Script\n    strategy=\"afterInteractive\"\n    src={`https://www.googletagmanager.com/gtag/js?id=${GA_MEASUREMENT_ID}`}\n  />\n  <Script\n    id=\"google-analytics\"\n    strategy=\"afterInteractive\"\n    dangerouslySetInnerHTML={{\n      __html: `\n        window.dataLayer = window.dataLayer || [];\n        function gtag(){dataLayer.push(arguments);}\n        gtag('js', new Date());\n        gtag('config', '${GA_MEASUREMENT_ID}', {\n          page_path: window.location.pathname,\n        });\n      `,\n    }}\n  />\n</>\n```\n\n### Step 3: Set Up Events\nTrack important user actions:\n\n#### Download Click Event\n```typescript\nimport { event } from \"@/lib/gtag\"\n\n// In your download button\nonClick={() => {\n  event(\"download_click\", \"engagement\", \"github_download\")\n}}\n```\n\n#### Feature View Event\n```typescript\neffect(() => {\n  event(\"feature_view\", \"engagement\", \"features_section\")\n}, [])\n```\n\n#### FAQ Interaction\n```typescript\nconst toggleFAQ = (index: number) => {\n  event(\n    \"faq_toggle\",\n    \"engagement\",\n    `faq_${index}`,\n    1\n  )\n  setOpenIndex(openIndex === index ? null : index)\n}\n```\n\n### Step 4: Connect GSC to Analytics\n1. In Google Analytics, go to Admin\n2. Click on your Property\n3. Go to \"Data display\"\n4. Find \"Search Console data\"\n5. Click \"Link\" and select your GSC property\n\n## 3. Troubleshooting Common Issues\n\n### Pages Not Indexed\n- Check robots.txt (shouldn't block pages)\n- Ensure sitemap is submitted\n- Check Search Console for errors\n- Request indexing manually in GSC\n\n### Low Click-Through Rate\n- Improve meta descriptions (add keywords)\n- Make titles more compelling\n- Add structured data for rich snippets\n- Test different variations\n\n### High Bounce Rate\n- Improve page load speed\n- Better content-to-query match\n- Clearer call-to-actions\n- Reduce ads/distractions\n\n### Poor Core Web Vitals\n- Optimize images\n- Minimize JavaScript\n- Use Content Delivery Network (CDN)\n- Implement lazy loading\n- Upgrade hosting if needed\n\n## 8.
